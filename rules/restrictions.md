# Restrictions — Segurança e Segredos

Restrições permanentes aplicáveis ao trabalho neste repositório:

* Nunca inventar credenciais.
* Nunca adicionar segredos à spec.
* Nunca adicionar segredos ao PRD.
* Nunca adicionar segredos ao AGENTS.md.
* Nunca registrar segredos em documentação ou código versionado.
* Nunca commitar `.env`.
* Nunca subir chaves, tokens ou senhas para o repositório.
* Variáveis necessárias ao projeto deverão ser representadas posteriormente por `.env.example`, sem valores secretos.
